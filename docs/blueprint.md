# **App Name**: FiscalFlow

## Core Features:

- Payment Record Input: Capture payment details including date, description, amount in bolivares, and BCV exchange rate.
- Automatic EUR Calculation: Calculate the equivalent amount in EUR based on the entered BCV exchange rate.
- Document Upload and Preview: Upload JPG payment documents and display a preview before submission.
- Data Storage in Firestore: Store the payment records and document metadata in Firestore.
- Image Storage in Firebase Storage: Store uploaded payment documents in Firebase Storage and keep metadata.
- Records Consultation Table: Show consultation records in tabular form.
- Records Table Filters: Filtering feature on the table consultation based on data and description

## Style Guidelines:

- Primary color: Dark green (#006241) inspired by Starbucks' brand.
- Background color: Cream (#f1e6d2), a desaturated, lighter tint of the primary green, providing a soft, inviting feel.
- Accent color: Golden (#cba052) to highlight key elements and actions.
- Body and headline font: 'Roboto', a modern, legible sans-serif font suitable for all text elements.
- Clean layout with individual payment records displayed in cards for easy readability and organization.
- Simple and recognizable icons for payment actions and record types.
- Subtle hover effects on buttons and interactive elements to enhance user experience.
